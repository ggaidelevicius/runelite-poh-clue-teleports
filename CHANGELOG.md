# Changelog

## 1.0.0

Initial public release of POH Clue Teleports.

- Recommend one available POH teleport for the active RuneLite clue using account-aware walking routes.
- Learn installed house facilities and available travel destinations automatically, with separate caches for each character.
- Compare routes through mapped walls, dungeon and floor transitions, physical passages, and usable agility shortcuts.
- Support location-specific clue challenges and alternative valid task sites.
- Highlight the recommended native menu entry, with one-time scrolling in the fairy ring travel log and portal nexus.
- Keep guidance in a compact overlay, with no sidebar or automatic teleport actions.

See the README for supported facilities, setup, route estimates, and known limitations. Plugin Hub availability depends on RuneLite's review and merge of the submission.
